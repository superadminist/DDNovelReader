# QYReader v2.0.7

这次更新集中处理联网语音切换到本地语音后的朗读错位，并减少朗读过程中主界面的闪烁。

## 朗读同步

- 网络语音合成失败后回退本地系统语音时，文字会等本地音频流实际开始再高亮当前句；手动切换本地音色也从当前句重新开始。
- 本地系统语音若未完整读完，程序不再把这句当作完成并提前跳到下一句。
- 朗读状态更新时减少正文重复滚动，避免高亮附近反复闪动。

## 窗口显示

- 增强主窗口画面显示不完整时的恢复，减少最大化及窗口状态切换后的残缺显示。

## 下载说明

- Windows 安装包：`QYReader-Setup-2.0.7.exe`。
- 安装包尚未进行代码签名，Windows SmartScreen 可能显示“未知发布者”；请确认下载地址来自本项目 GitHub Release，并使用随附的 `SHA256SUMS.txt` 核对文件。

本版通过自动化切换与桌面流程检查；真实弱网、扬声器同步和偶发半屏闪烁仍需在实际机器上复测。
