# QYReader v2.0.5

这次更新继续修复 2.0.4 遗留的朗读错句和主窗口圆角问题，让主面板与悬浮窗更容易对照当前听到的内容。

## 朗读文字与声音同步

- 点击暂停或恢复时，系统语音不会先把文字切到下一句；只有实际开始朗读下一句，主面板和悬浮窗才一起更新。
- 播放或暂停期间，主面板的自动滚动不会误改写朗读位置。
- 暂停后会把当前高亮句移到正文可视区域；很长的句子跨越多个正文分块时也能连续高亮。

## 窗口与提示

- 修复主窗口四角的黑色锯齿：普通窗口使用平滑圆角，最大化和全屏时保持直角。
- 主面板宽度较小时，网络异常提示会在自己的区域内收起显示，不再伸到播放按钮上；完整提示仍可通过悬停或辅助阅读获得。
