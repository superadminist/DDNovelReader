# QYReader v2.0.8

这次更新继续处理弱网下联网语音回退本地系统语音后的播放同步，确保主面板和悬浮窗显示的文字始终对应实际朗读内容。

## 朗读同步

- 联网语音回退到本地系统语音后，如果在当前句内快速点击暂停再播放，程序会重新朗读这一句，不会把被打断的句子当成已经完成而跳到下一句。
- 主面板和悬浮窗继续消费同一个播放状态；当前句只在本地语音实际重新开始后更新。

## 更新下载位置

- 安装版下载的新版本安装包保存到 `<安装目录>\data\updates`，与书架和阅读数据保持在同一应用数据目录中。

## 下载说明

- Windows 安装包：`QYReader-Setup-2.0.8.exe`。
- 安装包尚未进行代码签名，Windows SmartScreen 可能显示“未知发布者”；请确认下载地址来自本项目 GitHub Release，并使用随附的 `SHA256SUMS.txt` 核对文件。

本版通过播放服务、桥接和阅读服务自动化回归；弱网、系统语音和扬声器的真实桌面体验仍需在实际机器上复测。
