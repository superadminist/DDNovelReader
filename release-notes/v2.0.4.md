# QYReader v2.0.4

本次更新重点修复朗读文字与声音不同步，并改善网络语音恢复、设置体验和更新提示。

## 朗读同步修复

- 修复悬浮窗点击暂停时，文字可能提前切换到下一句、语音仍停留在上一句的问题。
- 修复 Edge 在线语音已经回退到系统语音时，暂停后可能错误推进朗读位置的问题。
- 音色或语速改变时，正在朗读的当前句会使用新设置重新开始，文字与声音保持一致。

## 网络语音恢复

- 网络异常并切换到系统语音后，主界面和悬浮窗会持续显示 Wi-Fi 状态提示。
- 软件会在后台低频探测网络；确认恢复后，在下一句开始前自动切回用户选择的在线音色。
- 恢复切换只发生在句子边界，不会在一句话中途突然换声；探测失败会逐步降低频率，减少网络抖动带来的反复切换。

## 设置中心

- 设置内容改为“常规”“朗读与悬浮”“更新与关于”三个分类，窗口更紧凑。
- 设置窗口补齐 24px 圆角，滚动仅发生在内容区，减少 Qt WebEngine 滚动时的整层闪烁。
- 主题、开关和朗读设置会立即在界面反馈并自动保存。

## 更新提示

- 检查到新版本时会弹窗展示本次优化内容，不再只显示一个下载入口。
- 用户可以查看完整发布说明、稍后处理、跳过当前版本或下载更新。
- 安装包仍需通过 SHA256 校验后才允许启动安装，不会静默更新。
