# QYReader v2.0.6

这次更新重点改善朗读时找回当前文字、主面板与悬浮窗的切换，以及播放/暂停时文字提前跳句的问题。

## 阅读与朗读

- 主面板播放条新增「定位当前朗读」按钮。手动滚动后，点击即可平滑回到当前高亮句；若这句尚未在当前正文窗口，会先加载对应正文再定位，不会改变朗读进度。
- 主面板和悬浮窗共享同一朗读状态；播放或暂停按钮不会自行推进文字，当前句以实际语音开始或恢复的事件为准。

## 窗口与设置

- 从主面板进入悬浮模式时隐藏主窗口；悬浮窗顶部新增返回主面板图标，一键退出悬浮并恢复主窗口，不中断朗读。
- 设置中「朗读与悬浮」与「常规」交换位置，打开设置后优先显示朗读选项。

## 下载说明

- Windows 安装包：`QYReader-Setup-2.0.6.exe`。
